# Unprompted — Atmospheric Impromptu Speaking Practice Website

Built with **React 18**, **TypeScript**, **Vite**, **Tailwind CSS**, **Web Audio API**, **MediaRecorder API**, **IndexedDB**, and a **Genuine ISO-BMFF M4A (AAC-LC / ALAC) Audio Container Muxer**.

## Deploy to Vercel

### Option 1: Vercel CLI (Fastest)
```bash
npm install
npx vercel --prod
```

### Option 2: GitHub + Vercel Dashboard
1. Push this repository to GitHub.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Vercel automatically detects **Vite** (`npm run build`, output directory `dist`) and applies the `vercel.json` headers.
